# Muldrel — versiones de prueba

Muldrel es un juego noir de detectives: inspeccionas la escena del crimen, interrogas a los sospechosos, conectas pruebas en el tablón y acusas con una teoría. En cada partida el culpable se sortea.

Este repositorio solo contiene **ejecutables para probar** (sin código fuente).

## Descargar y jugar
1. Ve a **[Releases](https://github.com/Elkeyaru/muldrel-releases/releases/latest)** y descarga `Muldrel-Alfa-<versión>-Windows.zip`.
2. Descomprímelo y abre `Muldrel.exe`.
3. Si Windows SmartScreen avisa, pulsa **Más información → Ejecutar de todas formas** (el ejecutable no está firmado).

**Requisitos:** Windows 10/11 de 64 bits y una gráfica compatible con DirectX 12 o Vulkan. Mejor con auriculares.
